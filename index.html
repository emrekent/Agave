03 / Why the competitors win these answers

The models are not guessing. They quote specific pages, and the winners own three page types Agave is thin on:

1. One page per ERP. ChatGPT cited stampli.com/erp/vista and avidxchange.com/integrations/procore almost verbatim. Agave has a single combined integrations page, so it does not surface for "AP automation for Viewpoint Vista" the way a dedicated page does.

2. Comparison and alternatives pages. On the alternatives question the model cited corpay.com and autopayables.com listicles. Agave has no "Agave vs" or "AvidXchange alternatives" content, so it is absent from the exact query where a buyer is switching.

3. A clear category label. The one time Agave appeared, it was filed as middleware, not AP. Agave now sells AP automation, but the model has not learned that, because the citable content still reads as an integrations API.

04 / Three moves to take the answers back

Move 1

Ship one answer page per ERP

A dedicated, directly-answerable page for AP automation on each ERP the buyer named: Sage 300 CRE, Viewpoint Vista, Foundation, Spectrum. Lead each with the plain-language answer the model wants to quote (what it does, job-cost coding, approvals, ERP write-back, payments), the way Stampli's ERP pages are built. This is the cheapest citation to win because the query is exact and the intent is high.

Move 2

Own the comparison and alternatives content

"Agave vs AvidXchange", "vs Stampli", "vs hh2", "vs Vergo", and an "AvidXchange alternatives for construction" page. This is the query where the model already admits Agave belongs once named. Publishing the page is how it gets named without being asked.

Move 3

Get into the roundups, and fix the label

The models trust third-party lists like autopayables.com and cashflowpick.com's "best construction AP 2026". Agave should be in them, positioned clearly as a construction AP automation platform, not an integrations API. That is outreach plus one sentence of positioning discipline repeated everywhere.

05 / How I would measure it

Re-run this exact set monthly across ChatGPT, Claude, Gemini and Perplexity. Track, per question: does Agave appear, in what position, with which cited source, and against whom. The number to move is simple: appearances in the answer, up from roughly one in eight today. It is a channel the posting says nobody at Agave has worked yet, which is exactly why it is winnable.
